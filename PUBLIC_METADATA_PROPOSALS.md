## How to apply safely

For each public repository, open its GitHub page, use the gear/settings beside **About**, enter the proposed text only for missing fields and add its proposed topic tags. Do not replace an existing value without checking its current accuracy. The changes require account-owner GitHub permissions; documentation commits do not modify About metadata.

## Quality rules

- Keep About text concise and avoid claiming a release, active provider integration or production deployment without evidence.
- Use topic tags to describe technology and actual product purpose, not a finished status.
- Preserve private project names in their private repositories; do not add them here.
- Repeat the audit whenever repositories are created, transferred or renamed.
