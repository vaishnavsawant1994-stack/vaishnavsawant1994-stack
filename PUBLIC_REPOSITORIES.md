## How to use this catalog

1. Open the project README for verified product intent, code boundaries, setup and historical qualification claims.
2. Examine exact-head CI and runtime evidence separately before assuming current release readiness.
3. Distinguish staged source, prototype UI, incomplete integration and owner-approved live releases.
4. Treat README-only placeholder repositories as reserved names, not executable applications.

This list covers **public** repositories only. It does not reveal private repository names or internal implementation documents. Descriptions and stage labels were reviewed at the catalog date and can change as development continues.
